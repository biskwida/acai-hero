# Swap in your real Acai Hero photos here 📸

The site is built so it looks complete **without any photos** — every visual is
hand-drawn CSS/SVG art. These are optional "slots" you can fill with your own
Instagram shots to make it even richer.

## How to swap

Drop a file with the **exact name** below into this folder (`public/images/`).
The site picks it up automatically — no code changes needed. If a file is missing,
a designed gradient + illustration shows instead, so nothing ever looks broken.

| Filename            | Where it appears            | Best shot                                  | Suggested size      |
| ------------------- | --------------------------- | ------------------------------------------ | ------------------- |
| `logo.png`          | Nav (top-left) — replaces wordmark          | Your logo on a transparent background      | ~480 × 180, transparent PNG/SVG |
| `hero-bowl.jpg`     | Hero, floating bowl         | A top-down hero açaí bowl, clean backdrop  | 900 × 900 (square)  |
| `story.jpg`         | "From the Amazon" story     | Hands holding a bowl, or the shopfront     | 1200 × 1500 (portrait) |
| `bowl-choco.jpg`    | Bestseller — Choco Paradise | Top-down Choco Paradise                     | 800 × 800 (square)  |
| `bowl-samba.jpg`    | Bestseller — Samba Bowl     | Top-down Samba Bowl                         | 800 × 800 (square)  |
| `bowl-nutty.jpg`    | Bestseller — Nutty Heaven   | Top-down Nutty Heaven                       | 800 × 800 (square)  |

Tip: square, top-down photos on a light surface look best and match the design.
JPG or WebP, ideally under ~400 KB each for fast loading.
